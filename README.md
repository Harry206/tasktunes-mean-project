TaskTunes is a web application that generates mood-based playlists for different tasks using the Spotify Web API. TaskTunes combines productivity and personalization by creating playlists that match a user’s current task and mood.
The application connects to the Spotify API to fetch songs, stores data in MongoDB, and provides an interactive Angular interface for users.


Features:

Generates playlists based on mood and task
Uses Spotify Web API for real-time music data
Stores playlists in MongoDB
Frontend built with Angular
Backend powered by Node.js and Express.js

Technologies Used:

Frontend: Angular
Backend: Node.js, Express.js
Database: MongoDB (Atlas)
API: Spotify Web API
Hosting: Render
